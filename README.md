# 💰 Budget Calculator

A simple and responsive Budget Calculator built using HTML, CSS, and JavaScript. Calculate your remaining balance by entering your monthly budget and expenses.

## ✨ Features

- Enter your monthly budget
- Enter your expenses
- Calculate your remaining balance
- Basic input validation
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/sweaditya/budget-calculator.git
   ```

2. Open the project folder:

   ```bash
   cd budget-calculator
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
